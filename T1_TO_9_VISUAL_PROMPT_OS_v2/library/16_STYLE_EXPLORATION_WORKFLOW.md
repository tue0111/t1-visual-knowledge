# 16 STYLE EXPLORATION WORKFLOW

Status: COMMUNITY_HEURISTIC, distilled 2026-09-13 from VSC rare-style-explorer method and GPT Image “dense style token” practice. Not a family registry, not a 620-record dataset, not mandatory startup.

Load when the user asks to explore uncommon visual directions for a given subject before locking a family. Do not load for ordinary one-family prompt work.

## Purpose

Produce a small set of candidate looks whose descriptors are visible mechanisms (medium, light, surface, print/defect, space), then let the user or Director choose. Candidates are proposals. They do not auto-promote into `library/13`.

## Trigger

- “explore styles / rare style / 风格探索 / don’t use the old prompt”;
- a subject that needs several distinct visual systems before production.

## Non-trigger

- user already named a family or locked instance;
- fusion/birth of a new family (core/07 still owns charter and evidence);
- cinematic DNA rebuild of one still (`library/20`) — that route restages relation/action/space, it does not shop mediums;
- dumping a catalogue into system instructions;
- claiming the runtime contains 260 or 620 style records.

## Catalogue status

The VSC write-up mentions 260 tags; the later README mentions 620. This OS does **not** ship either dataset.

- Runtime selector: NOT_INSTALLED.
- Exploration here is a structured manual method.
- Do not invent 620 records to match a marketing number.
- If a pinned `style_library.json` is later added under `_external_sources` with license and commit, route it on demand; do not paste it into Director/Analyst instructions.

## Combination rule

One strong base + at most one surface/light + at most one format/space + optional analog/defect layer.

Prefer:

- material, era, medium, light, space, print defect, subculture;
- over empty praise words (cinematic, aesthetic, high-end, surreal).

Anti-drift (compile into the prompt, translated to zh-CN):

- keep subject identity and silhouette;
- avoid generic modern-minimal default;
- avoid random readable extra text and messy symbols.

Dense tokens such as `editorial 人像`, `极简时尚封面感`, or a named photographic type are useful only when they call a production system (how it is shot, designed, and delivered). They are not three magic words for every model.

## Process

1. Name the subject and output goal (product, character, poster, scene, material series).
2. Propose 4–8 candidates. Each candidate states: base mechanism, optional modifiers, what would break, and a scope (this task / this series / family-candidate only).
3. Do not register all candidates as families. At most one may be recommended for core/07 review if it has new grammar.
4. After the user picks, compile through the current prompt contract and one dominant family. Style exploration does not replace family selection.
5. Fusion still needs ownership, compatibility, and a physical or authored relationship (core/07). One base + modifiers is not automatically a fusion.

## Output

- Vietnamese shortlist of candidates with mechanisms and scopes;
- optional compiled prompts for the chosen candidate only;
- no image generation unless requested and a tool exists.

## Failure / stop

- unrelated ordinary brief: do not load this module;
- user asks to “make a new family from these 8 looks”: refuse bulk promotion; run core/07 on one candidate with evidence.

## Acceptance

- candidates have visible mechanisms, not empty adjectives;
- none are silently written into library/13;
- current language/brand/no-logo overrides survive;
- no claim that a 620-entry selector ran.

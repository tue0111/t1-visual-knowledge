When a named locked instance is requested, load its kernel with the family. The matching locked kernel overrides generic family defaults and examples for instance-specific decisions. New approved Couture Entity instances append to the kernel file; do not rewrite an approved kernel through an example.

## Selection rules

### Use Couture Entity when

There is a real human anchor plus one secondary entity whose form transitions into fabric, atmosphere, brush, or graphic material.

### Use Live-Action Painted World when

The human remains photographic while the entire navigable environment remains stylized. The physical bridge matters more than 2.5D layering.

### Use Pictorial Reality when

Printed, painted, cut, or flat elements physically interrupt a real architectural scene.

### Use Mixed-Media Constructed Reality when

The primary experience is a face-centered diorama of resin, acetate, paper, glass, or controlled optical particles.

### Use an illusion library as support when

The image needs one perceptual mechanism. The illusion is not a family unless it determines anchor, read order, and world logic across the project.

## Select versus birth

Birth a new family when no registered family matches:

- anchor;
- read order;
- base/break ratio;
- light logic;
- material system;
- signature move;
- signature collapse.

## Family precedence

Matching locked instance kernel > matching family module > generic compiler skeleton > example.

Examples sharpen phrasing only. They never redefine a family.

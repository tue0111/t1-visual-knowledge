# EXAMPLE — 清虚鹤引·阴册

Family: Couture Entity  
Mode: Taoist portrait

## 母版锁

~~~text
【母版锁 · 清虚鹤引·阴册】

生成一张3:4竖构图的高级道家形而上时尚肖像。核心为真实摄影成年东亚女性、一只丹顶鹤高定雕塑、一个黑白太极境界光环与连续的“白羽拂尘一体流”。整体属于清虚阴册：庄重、清静、冷冽、克制，不是普通道士写真，不是影视道袍，不是仙侠游戏角色，也不是人物与宠物鸟合影。

人物约二十五至三十二岁，成熟冷静，真实骨相、真实皮肤与有内在生命的深色眼睛。深色虹膜保持真实明暗质量，上眼睑自然轻覆；极柔的大面积眼神光来自侧前上方，落在角膜外上缘，不直射瞳孔中心，也不照亮瞳孔。黑发采用简洁高髻，少量碎发自然落在脸侧。脸部、眼睛与微表情是第一视觉。

丹顶鹤结构与比例真实，象牙白身羽干燥、柔软、层叠，颈部与飞羽末端为墨黑色，头顶只有唯一一点朱砂丹顶；鹤颈形成清晰的曲线并把视线引回人物脸部。朱砂丹顶是全图唯一暖色。

人物手持一柄乌木嵌玉柄拂尘，雪白马尾长丝是“白羽拂尘一体流”的明确起点与动作轴：拂尘白丝先被同一阵风拉长、变软，再转化为与丹顶鹤飘羽同向的羽绒薄纱带，随后化为克制薄雾，最远端边缘转为羽毛至水墨笔触。拂尘、白丝、鹤羽、薄纱、薄雾与水墨边缘共享同一流向、透视、主光和连续边缘；拂尘绝不是孤立道具。

人物穿高级化交领白色道家长袍，以象牙月白和银灰为主，只有克制的云水暗绣。真丝保持洁白发光、真实各向异性光泽、自然垂坠与纤维厚度；背景比白衣压暗二至二点五档，白衣绝不发灰、发脏或塑料化。

人物头后只有一个黑白太极光环，由阴阳鱼构成，不生成八卦爻线。光环采用非矢量的数字绘画笔触与三维修仙动画境界光环质感，微弱自发光、柔边、压暗、半透明，直径约为头宽的一点五至二倍。符号越强，光学表现越压低；它不能变成清晰标志、贴纸或平面商标。

背景为二维水墨山水与大面积留白，前景只保留少量景深虚化松枝，形成松鹤延年的安静暗示。全图色板锁定为墨黑、象牙月白、银灰与一点朱砂；朱砂只属于丹顶，唇色仅以极轻冷玫瑰呼应。禁止暖黄、橙色和古金成为主色。

冷月白主光从左前上方照亮脸、白衣、拂尘白丝与鹤羽；银色轮廓光描出白丝、飞羽与薄纱边缘；负补光保持面部结构。人物、丹顶鹤、拂尘和太极环共享同一光向，但太极环亮度必须受压。

【固定品牌角标】
画面右下角仅允许出现一个极小衬线体品牌角标“T1 to 9”。除此之外禁止任何文字、标志、签名和水印。
~~~

## 分镜

~~~text
【分镜 · 拂尘引鹤】

85至100毫米人像镜头，胸像构图。人物正面略偏左，视线平静地越过镜头并有明确远方目标。人物一手在胸线下方持乌木嵌玉拂尘柄，拂尘白丝从画面下方沿对角动作轴上升，在靠近肩颈处被风拉长并转为羽绒薄纱带。拂尘柄与手部清楚可读，但不遮挡脸部。

丹顶鹤头部位于人物肩后上方，象牙白羽、墨黑颈羽与飞羽末端层次真实，唯一朱砂丹顶清楚但面积极小。鹤颈形成优雅曲线，先接住拂尘白丝的动作方向，再把视线引回人物眼睛。飘羽、羽绒薄纱带、薄雾和水墨边缘沿同一风向逐层后退。

黑白太极光环位于人物头后，直径约为头宽一点七倍，仅保留阴阳鱼，不出现八卦爻线。光环为压暗半透明的数字绘画笔触，边缘柔化并带极弱自发光。二维水墨山水保持大留白，前景一小段虚化松枝形成景深。

脸部、眼睛与角膜外上缘的柔和眼神光最清晰；拂尘柄、近脸白丝、丹顶鹤头部与颈部次清晰；远端薄纱、薄雾、太极环和山水逐层降低细节。强制丹顶鹤真实解剖、单一长颈曲线与拂尘作为流的起点，不得生成普通白鹭、多人、多个白鹤或翅膀遮脸。
~~~

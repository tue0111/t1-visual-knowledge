# Example 05 — couture entity

Route: `family_selection` → `Couture Entity` → locked kernel only when instance matches.

## 母版锁

~~~text
【母版锁】

成年人物与一只由锦鲤鳞片、丝绸褶皱和湿润高光共同组成的高定实体形成一个命名系统；实体不遮脸，右下角仅有“T1 to 9”。

~~~

## 分镜

~~~text
【分镜】

第一视觉是人物眼神，第二视觉是实体从肩线向裙摆的连续流动；鳞片只在转折与受光边缘出现，裙摆保留重量、褶皱与接触阴影。

~~~

除右下角指定的“T1 to 9”品牌角标外，禁止其他文字；禁止普通宠物、道具动物、实体遮脸、随机鳞片铺满、廉价戏服。

~~~

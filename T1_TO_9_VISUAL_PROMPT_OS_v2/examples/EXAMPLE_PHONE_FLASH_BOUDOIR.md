# EXAMPLE — 古董珠宝闺阁手机闪光

Family: Phone-Flash Jewelry Boudoir  
Mode: single full-body snapshot

## 母版锁

~~~text
【母版锁 · 古董珠宝闺阁手机闪光】

生成一张2:3竖构图的高端智能手机后置镜头闪光抓拍。整体像朋友在昏暗古董珠宝陈列室中用手机突然拍下的一瞬，不是单反人像，不是电影棚拍，不是婚纱摄影。

主体是一位成年东亚女性，成熟柔和、安静克制，真实脸型、真实皮肤纹理与自然眼神。服装为低饱和浅玉色古风灵感长裙，使用薄纱叠层、真实丝绸垂坠与克制金线，保持端庄、轻盈、不暴露。

场景为黑漆描金柜、玻璃珠宝柜、少量珍珠、玉器、瓷瓶、首饰盒与小型暖色实景灯。只激活玻璃、漆木、玉石三类主要材质，其他细节降低清晰度。

相机为高端智能手机后置镜头，近似二十四至二十八毫米的小型传感器透视，景深较深，不使用长焦压缩和强散景。柔和白色正面手机闪光主要落在人物脸部、手势与衣料，背景更暗、低对比、低饱和但仍可读。画面略柔和，细节可见但不呈现专业画报式超锐。

【固定品牌角标】
画面右下角仅允许出现一个极小衬线体品牌角标“T1 to 9”。除此之外禁止任何文字、标志、签名和水印。
~~~

## 分镜

~~~text
【分镜 · 柜边回望】

平视全身或接近全身构图。人物刚刚经过玻璃珠宝柜，听到身后声音后自然停步并轻微回头。一只手搭在黑漆柜边，另一只手放松地整理袖口。动作像真实生活瞬间，不是职业模特摆姿。

手机闪光在脸、手、浅玉色丝绸和最近的玻璃边缘形成清楚但克制的反光。远处暖灯只提供少量环境层次，不形成电影轮廓光。背景珠宝仍能辨认，但不得比人物更亮。

强制手机抓拍透视与较深景深，不得变成85毫米单反棚拍。
~~~

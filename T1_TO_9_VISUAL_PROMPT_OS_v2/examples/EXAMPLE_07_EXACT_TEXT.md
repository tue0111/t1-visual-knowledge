# Example 07 — exact text exception

Route: `text_logo` → project contract → machine text review.

## 母版锁

~~~text
【母版锁】

右下角仅允许一个极小、清晰的衬线体品牌角标，文字逐字准确为“T1 to 9”，不发光、不加边框、不遮挡主体。

~~~

## 分镜

~~~text
【分镜】

中景人物与建筑留出右下角安全区；角标位于安全区内，大小克制，与暖灰色调协调。

~~~

## 通用负面提示词

~~~text

禁止除“T1 to 9”外的任何文字、标志、签名和水印；禁止拼写错误、大小写错误、空格错误、缺字、多字、重复或乱码。

~~~

Acceptance: exact literal and sole text exception.

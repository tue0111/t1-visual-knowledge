# EXAMPLE — 锦鲤绸鳍高定

Family: Couture Entity  
Mode: single portrait calibration

## 母版锁

~~~text
【母版锁 · 锦鲤绸鳍高定】

生成一张3:4竖构图的高级东方幻想时尚肖像。核心为真实摄影成年东亚女性、二点五维红白锦鲤高定雕塑与一股连续的“锦鲤绸鳍流”。整体不是普通和服写真，不是人物与宠物鱼合影，不是水族馆场景，也不是纯插画。

主体约二十五至三十二岁，成熟、安静、克制，真实骨相、真实皮肤纹理、自然毛孔与有生命的深色眼睛。脸部、眼睛与微表情是第一视觉，也是全图最清晰、最真实的区域。

人物穿深青绿、朱红、象牙白与旧金色构成的改良和式高级定制服装。厚重真丝锦缎具有方向性高光、真实垂坠、宽袖与层叠腰封；金线刺绣数量克制，禁止旅游和服与廉价艺伎装扮。

一条大型红白锦鲤作为第二视觉，结构与比例真实可信，鳞片具有湿润表面反光。锦鲤身体、夸张展开的鱼鳍、半透明薄绸与少量抽象水纹必须融合成同一股“锦鲤绸鳍流”：鱼鳍就是丝绸，丝绸就是水中展开的鳍膜，共享同一方向、透视、主光和连续边缘。

色彩从象牙白、奶油金、柔珊瑚、朱红、透明琥珀过渡至深青绿。背景为压暗的朱红日轮与深色摄影棚场域，只保留少量金色碎屑作为低细节支撑。

大型柔光箱从左前上方照亮脸、肩颈、真丝与近脸鳞片；右侧负补光雕刻骨相；极窄轮廓光描出鱼鳍、发丝与丝绸边缘。背景比人物暗二至二点五档。

【固定品牌角标】
画面右下角仅允许出现一个极小、克制的衬线体品牌角标“T1 to 9”。除此之外禁止任何文字、标志、签名和水印。

每次只生成一张画面，不生成拼图、九宫格或多个备选。
~~~

## 分镜

~~~text
【分镜 · 赤鳍回流】

85毫米人像镜头，胸像至腰上构图，人物位于中央略偏左，身体轻微转向画面右侧，平静直视镜头。锦鲤头部靠近人物肩线但不遮挡五官，鱼身从背后形成优雅弧线；宽大鱼鳍在人物另一侧展开并逐渐转化为半透明丝绸袖摆。

前景仅有一小段柔化鳍膜形成景深，中景人物脸部、锦鲤头部与近脸鳞片最清晰，后方朱红日轮柔化压暗。视觉路径必须从眼睛进入，经过锦鲤头部和鱼身弧线，再沿绸鳍回到人物脸部。

强制静止权威胸像，不得生成水下全身游泳、人物抱鱼或普通宠物合影。
~~~

# EXAMPLE — 醉墨翡君

Family: Emerald Ink Sovereign  
Mode: single motion calibration

## 母版锁

~~~text
【母版锁 · 醉墨翡君】

生成一张3:4竖构图的高级电影感仙侠时尚图像。主体是一位二十五至三十二岁的成年东亚女性，成熟清冷、疏离、具有高阶女尊气质。真实骨相、真实皮肤纹理、深色有生命的眼睛与长墨黑发。

唯一完全真实、最清晰的区域是被克制机顶闪光照亮的脸部和上半身。脸部绝不可变成绘画、笔触、运动模糊或错觉碎片。

画面以约百分之六十五至七十的真实电影摄影为基础，约百分之二十为方向明确的翠绿数字笔触溶解，并允许约百分之十的一种单一错觉机制。真实运动模糊、飞发、衣摆与数字笔触必须共享同一运动矢量；离脸部越远，摄影越逐渐转化为笔触。

人物穿深翠绿、黑玉色、暗青与炭灰构成的极简权力感修仙长袍。真丝与水洗缎具有重量、方向性高光、挺拔肩线、清楚腰线和长袖长摆。肤色保持自然中性，不染绿，不出现暖黄橙褐油画偏色。

镜头使用35至50毫米自然透视。正面薄闪光建立真人锚点，后方冷色轮廓光分离发丝和肩线，背景为压暗黑石大殿与低细节翠色雾气。

【固定品牌角标】
画面右下角仅允许出现一个极小衬线体品牌角标“T1 to 9”。除此之外禁止任何文字、标志、签名和水印。
~~~

## 分镜

~~~text
【分镜 · 翡翠旋身】

35毫米镜头，人物在黑石大殿中央快速旋身，身体支撑清楚，双眼睁开并看向旋转方向。瞬间闪光冻结脸部、眼睛、肩部与靠近身体的袖口；远端长袖、长发和裙摆沿同一弧线产生真实运动拖影，并逐渐转化为翠绿与黑玉色数字笔触。

本镜头只使用运动溶解，不加入碎镜、双重曝光、焦散或其他错觉。笔触越远离脸越明显，背景柱体只在运动方向上轻微刷开。强制睁眼旋身，不得回到闭眼后仰、持酒杯和慵懒瘫坐。
~~~

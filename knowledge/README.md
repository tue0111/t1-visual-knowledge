## Tầng 2 — Tư duy (`mindset/`) — chưa
Brief → mục đích ảnh → người xem đọc gì đầu tiên → chọn trục chính. Chế độ poster / cinema / candid quyết định trục nào làm chính.

## Tầng 3 — Viết prompt trục chính/phụ (`writing/`) — chưa
Trục chính (1, tối đa 2): nhiều chữ nhất, có bằng chứng, negative bảo vệ. Trục phụ: ngắn, phục vụ. Map vào 母版锁 / 分镜 / 通用负面提示词.

Mỗi module gom phần repo đã có (link, không chép), rồi bổ sung bằng nghiên cứu web và case từ ảnh thật.
